## Completed application

mello runs locally with Vue, FastAPI and SQLite, for fictional coursework demonstrations. Its revised Practice library offers three reviewed, fixed one-minute guides: **4/6 paced breathing** (six cycles at one second/count), **5–4–3–2–1 grounding** (five twelve-second steps), and **STOP** (four fifteen-second steps). No written response, check-in or model call is required. Pause allows more time; Resume is explicit; End is immediate. Independent bundled Crisis support remains available. The prototype does not diagnose, provide therapy, promise improvement or imply monitoring, and is not deployed as a support service.

The assistant exists **only in a bottom-right popup**, with readable replies and optional local voice. The top bar contains Practice, History and Crisis support. Original generated coastal scenery is decorative; solid task surfaces, muted colors, keyboard controls, text/reduced-motion cues, larger-text/higher-contrast options and step announcements preserve access choices. Higher contrast removes the hero photo. Sensory recall/no-required-movement options are explicit interface adaptations, not clinically validated substitutes.

SQLite stores dated conversations, actual skill/content identity, session events/outcomes, available timing, explicit breathing-cue preferences and a reversible standard/brief reply profile. History distinguishes Completed, Stopped, Interrupted and Not started. Failed writes remain Not saved with Retry/unsaved exit; missing recovered timing is unknown. Optional factual profile/history reply context is deliberately **breathing-specific**, so Grounding/STOP records cannot be presented as breathing outcomes. Reset, override, reuse and deletion remain explicit.

The local model selects an allowlisted catalog topic, including the new skills topic. Reviewed local rules tailor approved text; the model does not receive raw profile/history, prescribe advice, set steps/timing, write preferences or navigate. Prompt `catalog-selector-v12`, catalog `app-help-v6`, renderer `profile-copy-v1`. Mocks are default and the host-controlled attempt cap remains at most 50, counting preload, failures and retries.
