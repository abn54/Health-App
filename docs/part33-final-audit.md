## Generated code the student should be ready to explain

The process recording's `watch(() => audioState.value.busy, ...)` waits for speech busy→idle and then Vue `nextTick`. When Stop removes a temporary focused control, the watcher restores focus **only if it escaped the open popup**, avoiding taking focus from someone still typing. A document **capture** Escape handler receives the event even if focus is BODY; it prioritizes support, then calls the existing popup close function, which restores launcher focus. Mount/unmount add/remove the listener. This fixes the observed keyboard failure without giving the model navigation or timer authority.

The new `GuidedExercise.read()` inherits one monotonic elapsed-time source, then maps elapsed time to an allowlisted step index, clamped to the final step. Five grounding steps divide60000ms into12000ms segments; four STOP steps use15000ms. Pause/Resume/End/interruption remain in the parent engine. It selects reviewed application data, not model-generated instructions. [Source](../frontend/src/guided.js).
